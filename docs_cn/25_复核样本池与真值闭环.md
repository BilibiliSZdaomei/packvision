# 复核样本池与真值闭环

> 日期：2026-05-28  
> 目标：让失败、低置信、人工改框、异常材质和多视角冲突的测量记录自动沉淀成可追溯样本，后续用于现场复核、误差报告和 AI 插件训练。

## 1. 这次新增了什么

新增接口：

```text
GET /api/review/samples
GET /api/review/export.csv
GET /api/review/truth-template.csv
```

新增 UI：

```text
PackVision 首页左侧导航 -> 数据中心 -> 复核
```

复核不是仓库员工日常工作台。它是主管/工程人员看的低置信样本池，用来追溯为什么某些测量需要重拍、人工量真值或后续训练模型。

复核页会显示：

- 需要复核的样本数量。
- 高优先级样本数量。
- 最常见的复核原因。
- 单号、状态、置信度、包装分类、材质风险、建议动作。

## 2. 哪些记录会进复核池

系统会从历史记录里自动筛选，不要求仓库员工手动选择。

触发条件包括：

- 测量状态不是 `measured`，例如 `review`。
- 置信度低于 `0.65`。
- 深度图稀疏、空洞、噪声大或台面不稳定。
- 反光、透明、深黑吸光、易变形等异常材质。
- 异形件、软包、大件异形需要人工边界复核。
- 多相机/多视角尺寸冲突。
- 使用了人工框、人工高度或其他人工修正。
- 推荐动作里包含重拍、复核、人工校验、现场真值验证。

## 3. 现场怎么用

仓库日常不需要先选模式。推荐流程：

1. 扫单号。
2. 放件。
3. 自动测量。
4. 普通样本直接保存历史。
5. 低置信、异常材质、异形件、多视角冲突自动进入复核池。
6. 工程人员或主管定期导出复核 CSV。
7. 用卷尺/卡尺补充真值，再导入验收评估。

导出地址：

```text
http://127.0.0.1:8765/api/review/export.csv
```

真值填写模板：

```text
http://127.0.0.1:8765/api/review/truth-template.csv
```

它会把复核样本的 `measurement_id`、单号、包装分类、材质风险、系统测量长宽高自动填好，留出 `truth_length_mm`、`truth_width_mm`、`truth_height_mm` 给现场用卷尺/卡尺填写。

## 4. 和真值模板的关系

复核池解决“哪些样本值得复核”。

真值模板解决“复核后怎么记录人工真值”：

```text
http://127.0.0.1:8765/api/validation/trial-template.csv
```

现场做法是：

- 先从复核池导出真值模板。
- 找到对应单号和测量记录。
- 用卷尺/卡尺填写 `truth_*` 列。
- 再用 `/api/validation/evaluate-csv` 评估误差。

## 5. 对后续 AI 插件的意义

这个复核池是未来 YOLO、分割、OBB、轻量 ONNX 插件的数据入口。

基础包仍然保持轻量，不内置大模型。等真实仓库样本积累后，再把这些复核样本整理成训练集：

```text
review samples -> truth CSV -> image/depth artifacts -> annotation dataset -> optional AI plugin
```

这样可以避免一开始就塞入大模型，也能让模型真正学习汽车备件仓库里的包装、异形件和异常材质。
