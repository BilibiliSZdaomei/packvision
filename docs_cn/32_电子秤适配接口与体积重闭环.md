# 电子秤适配接口与体积重闭环

## 目标

PackVision 的专业 DWS 工位不能只算尺寸，还要把实重、体积重、计费重串起来。当前阶段先完成轻量接口层：

- 基础包内置轻量 `pyserial`，支持常见 RS232/USB 转串口电子秤；USB HID 作为后续插件。
- 没有电子秤时，保留手动实重输入。
- 有电子秤时，通过统一 adapter 接口读取重量。
- 后续不同国家仓库换电子秤时，不需要改测量主流程。

## 新增接口

```text
GET /api/scale/status
POST /api/scale/read
```

`/api/scale/status` 用于 UI 常驻显示：

- `manual_ready`：当前使用手动实重兜底。
- `auto_weight_ready`：电子秤已有稳定读数。
- `auto_weight_unstable`：读到了重量，但秤端标记为未稳定。
- `adapter_configured_waiting`：已配置电子秤 adapter，但还没读到稳定重量。
- `adapter_error` / `adapter_dependency_missing`：串口、协议或依赖异常，仍保留手动输入。

`/api/scale/read` 用于后续硬件版主动读取电子秤。当前基础包如果没有配置硬件，会返回 `manual_required`，不会阻断尺寸测量。

## 当前支持的来源

| 来源 | 用途 | 配置 |
| --- | --- | --- |
| `manual_entry` | 默认手动输入实重 | 无 |
| `mock` | 无硬件干跑和演示 | `PACKVISION_SCALE_SOURCE=mock` + `PACKVISION_MOCK_SCALE_KG=7.35` |
| `usb_hid` | 预留 USB HID 电子秤 | 后续插件启用 |
| `rs232_serial` | 已支持串口/RS232 电子秤 | `PACKVISION_SCALE_SOURCE=rs232_serial` + `PACKVISION_SCALE_SERIAL_PORT=COMx` |

RS232 常用配置：

```text
PACKVISION_SCALE_SOURCE=rs232_serial
PACKVISION_SCALE_SERIAL_PORT=COM7
PACKVISION_SCALE_SERIAL_BAUDRATE=9600
PACKVISION_SCALE_SERIAL_TIMEOUT_MS=500
PACKVISION_SCALE_SERIAL_READ_LINES=3
```

已支持解析的常见格式：

```text
ST,GS,+   7.350kg
US,GS,+001250 g
ST,+ 10.0 lb
```

## UI 行为

- 工作台重量区域新增“电子秤”状态。
- 工作台新增“读取电子秤”按钮，用于现场主动读一次秤。
- 如果读到稳定电子秤重量，会自动填入实重输入框，并重新计算计费重。
- 如果未接电子秤，显示“手动实重兜底”，仓库员工仍可手动输入。

## 为什么这样做

海外仓电脑配置、USB 设备、电子秤型号都可能不同。基础包保持轻量，先统一 API 和 UI 语义；真正接秤时，只需要补 adapter，不要重写业务流程。
