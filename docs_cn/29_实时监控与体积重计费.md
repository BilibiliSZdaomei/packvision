# 实时监控与体积重计费

## 目标

PackVision 的现场模式应该像专业尺寸采集软件：相机持续采集，系统持续刷新尺寸、稳定帧、帧率和运行时长；仓库人员只需要扫码、输入实重、确认保存。

## 当前实现

- 实时采集接口持续运行：`/api/depth/live/start`、`/api/depth/live/state`、`/api/depth/live/confirm`。
- 工作台新增采集监控指标：实时状态、帧数、稳定帧、模拟/硬件状态、FPS、运行时长、测量次数、采集后端。
- 工作台新增常驻重量区：实重输入、体积重规则选择、体积重/计费重预览。
- 后端新增体积重规则表接口：`/api/weight/volumetric-rules`。
- 历史记录新增可追溯字段：实重、体积重、体积重规则、计费来源、计费重量。

## 体积重规则

默认规则仍是 `standard_6000`，也就是：

```text
体积重 kg = 长 cm × 宽 cm × 高 cm / 6000
```

系统内部以升/千克保存规则：

| 规则 | 场景 | 计算 |
| --- | --- | --- |
| `express_5000` | 快递/空运偏严格场景 | 体积 L / 5 |
| `standard_6000` | 默认仓配场景 | 体积 L / 6 |
| `economy_8000` | 经济陆运或宽松场景 | 体积 L / 8 |

计费重逻辑：

```text
计费重 = max(实重, 体积重)
```

如果没有输入实重，系统仍会按尺寸给出体积重和计费重候选；如果输入实重，历史记录会保存计费来源是 `actual_weight` 还是 `volumetric_weight`。

## 仓库操作

1. 扫描单号，或上传条码图片识别单号。
2. 把包装/异形件放到深度相机视野内。
3. 看实时监控是否进入“稳定可记录”。
4. 称重后输入实重。
5. 按仓配规则选择体积重表。
6. 点击“记录当前稳定结果”。

## 后续增强

- 按国家、承运商、仓库维护独立体积重规则。
- 支持从 WMS/ERP 单号接口自动带出渠道规则。
- 对接电子秤串口/USB HID，减少人工输入实重。
- 在三相机模式下把多视角融合结果直接进入同一套计费重计算。
