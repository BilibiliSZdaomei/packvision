# Astra Pro 场景化调试清单

## 这次补强的目标

PackVision 的深度相机页不再只按“长条件 + 反光件 + 双相机”生成固定调试清单。现场人员可以直接选择：

- 包装类型：标准纸箱、长条件、异形/软包、大件异形。
- 材质/表面：普通、反光/金属、透明/灯罩、深黑吸光、易变形软材。
- 相机数：1 台或 2 台。

点击“调试清单”后，系统会调用 `/api/depth/workflow-guide`，按当前组合返回到货准备、拍摄姿态、采集步骤、是否需要主板升级等建议。

## 现场怎么用

1. 先在“测量”页录入或扫码单号，选择包装类型和材质，上传顶部/侧面照片或先跑演示。
2. 如果测量结果里已经生成行业摘要，系统会把深度页的包装类型和材质同步成当前备件的场景。
3. 进入“深度”页，确认包装类型、材质、相机数。
4. 点击“调试清单”，按页面返回的准备项逐条检查。
5. 相机到货后，先用官方上位机确认 RGB 和 Depth 都有画面，再运行“采集探测”。
6. 用已知尺寸纸箱做第一条历史记录，再进入长条件、异形件、反光/透明材质的试运行。

## 推荐流程

### 标准纸箱

- 优先使用顶部深度 ROI。
- 侧面照片或深度高度作为交叉复核。
- 适合作为相机到货后的第一批验收样本。

### 长条件

- 抬高或斜向摆放，保证完整长度进入画面。
- 双相机时优先检查有源 USB 3.0 Hub、数据线长度和不同 USB 控制器。
- 需要人工端到端真值复核，避免长轴被截断。

### 异形/软包

- 使用深度对象掩膜流程。
- 测量后必须看掩膜边界，必要时手动修正范围。
- 软包、泡棉、缠绕膜等易变形物料要复拍一次，确认最大外廓。

### 反光、透明、深黑材质

- 这些材质容易造成深度噪声或空洞。
- 调整角度、避开强反光、使用稳定室内光。
- 必要时贴哑光胶带或使用人工复核，不要把单次深度结果直接当最终值。

## 验收口径

- 每种包装类型至少按验证计划采样。
- 每种异常材质都要留样本。
- 每条记录要带单号、时间戳、测量方法和历史记录。
- 统计页可导出后台调用与测量次数，便于汇报试运行工作量。
