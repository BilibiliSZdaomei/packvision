# Measuring-Size-of-Objects-with-OpenCV 中文介绍

## 项目来源

仓库地址：`https://github.com/Practical-CV/Measuring-Size-of-Objects-with-OpenCV`

该项目是一个基于 OpenCV 的物体尺寸测量示例，灵感来自 PyImageSearch 的经典教程。它使用已知尺寸的参考物，计算图片中的像素比例，再估算其他物体的尺寸。

## 解决的问题

它解决的是“在一张图片中，如何根据已知尺寸的参考物估算其他物体尺寸”的问题。

典型场景：

- 桌面上放多个物体。
- 左侧或固定位置放一个已知尺寸参考物。
- 用近似俯视角拍照。
- 程序找出轮廓并输出尺寸。

## 核心算法流程

主要脚本：`object_size.py`

流程如下：

1. 读取输入图片。
2. 转灰度图。
3. 高斯模糊，降低噪声。
4. Canny 边缘检测。
5. 膨胀和腐蚀，连接断裂边缘。
6. 找外部轮廓。
7. 按从左到右排序轮廓。
8. 对每个轮廓计算 `cv2.minAreaRect` 最小旋转外接矩形。
9. 计算矩形四边中点。
10. 用第一个参考物的已知宽度计算 `pixelsPerMetric`。
11. 用 `像素距离 / pixelsPerMetric` 得到真实尺寸。
12. 在图片上标注尺寸。

## 运行方式

示例命令：

```powershell
python object_size.py --image images/example_01.png --width 0.955
```

其中 `--width` 是参考物真实宽度，项目示例使用美国 quarter 硬币，单位为英寸。

## 值得借鉴的地方

对 PackVision 有价值的点：

- 经典的“参考物 + 像素比例”算法结构。
- 轮廓排序、最小外接矩形、中点测距的实现清晰。
- 代码短，适合快速理解尺寸测量原理。
- README 明确说明了俯视拍摄、镜头畸变等限制。

## 局限

该项目局限也很明显：

- 默认参考物是“最左侧物体”，不够工程化。
- 参考物识别依赖位置，而不是稳定的编码标记。
- 不适合复杂背景。
- 不处理高度。
- 不处理透视校正。
- 单位和参考物配置较硬编码。

## 对 PackVision 的整合建议

PackVision 不建议直接复制这个项目的参考物逻辑，而是吸收它的轮廓测量结构：

- 保留 `minAreaRect` 和中点测距思想。
- 参考物从普通硬币升级为 ArUco。
- 增加质量提示和置信度。
- 增加上传接口和结果证据图。
- 加入手动四角校正作为轮廓识别失败时的 fallback。
