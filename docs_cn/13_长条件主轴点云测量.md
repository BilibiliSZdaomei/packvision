# 长条件主轴点云测量

汽车备件里的减震器、饰条、管件、保险杠附件经常不是横平竖直摆在台面上。如果只按图像 X/Y 方向取点云范围，斜放时会低估真实长度，或者把宽度解释得不稳定。

本轮给异形件深度测量接口增加了 `footprint_method`：

- `axis_aligned`：默认模式，沿 X/Y 轴取点云外接范围，适合摆放端正的纸箱、方盒、规则包装。
- `principal_axes`：主轴模式，先根据目标点云自动计算最长方向，再沿主轴和副轴取长度/宽度，适合斜放的长条件、管件、饰条、软包条形件。

## 调用方式

接口仍然是：

`POST /api/depth/measure-object`

新增字段：

```json
{
  "footprint_method": "principal_axes"
}
```

返回结果会新增：

- `depth.footprint_method`：实际使用的足迹算法。
- `depth.orientation_deg`：主轴相对图像水平轴的角度，范围约为 `-90` 到 `90` 度。
- `quality_flags` 中的 `principal_axis_extent_used`：表示本次使用了主轴点云尺寸。

## 仓库操作建议

- 长条件、管件、饰条：优先使用 `principal_axes`。
- 标准纸箱：继续使用默认 `axis_aligned` 或深度 ROI。
- 如果长条件被遮挡或没有完整进入 ROI，主轴模式也无法恢复缺失长度，需要重新摆放或分段复核。
- 主轴角度只用于测量，不要求仓库人员理解或手动输入。

## 与异形件的关系

`principal_axes` 不是替代目标掩膜，而是在目标掩膜已经分离出工件后，改进“长宽方向”的计算方式。它适合长条形异形件，不适合多分叉、环形、L 形特别明显的零件直接当最终计费尺寸；这些仍然建议人工复核或按业务规则取外接范围。
