# PackVision 后续整合路线建议

## 阶段一：把当前 MVP 做得更可用

目标：让普通用户能稳定拍出可测图片。

建议功能：

- 拍照引导图。
- 示例图片。
- 标记打印说明。
- 上传失败原因提示。
- 手动四角点选。
- 标注图下载。
- 测量记录保存。

## 阶段二：提升单目照片准确性

目标：减少角度和镜头畸变误差。

建议功能：

- 相机标定。
- 图像去畸变。
- 透视校正。
- 多 ArUco 平面校准。
- 固定打包台校准模式。

可参考：

- `aruco_markers`
- `Automatic-Workspace-Calibration-Based-on-Aruco`

## 阶段三：接入仓库业务流程

目标：从“测量工具”变成“仓库量方记录系统”。

建议功能：

- 订单号。
- SKU。
- 条码扫描。
- 重量。
- 操作员。
- 时间戳。
- 原图和标注图证据。
- CSV/Excel 导出。
- 本地数据库。

## 阶段四：接入硬件

目标：提升效率和稳定性。

可选硬件：

- USB 摄像头。
- 工业相机。
- 扫码枪。
- 电子秤。
- 深度相机。
- 固定光源。

建议先接：

1. 扫码枪。
2. 电子秤。
3. USB 摄像头。
4. 深度相机。

## 阶段五：商业量方版本

目标：接近 DWS 或商用 parcel dimensioning 系统。

关键能力：

- 自动采集。
- 自动识别。
- 自动量方。
- 自动称重。
- 条码绑定。
- 证据图保存。
- 异常复核。
- 与 ERP/WMS/API 对接。

## 技术路线判断

如果只是低成本 MVP：

- 手机照片 + ArUco + 人工高度即可。

如果要仓库长期使用：

- 固定摄像头 + 打包台校准 + 电子秤 + 扫码枪。

如果要商业级自动量方：

- 深度相机或多相机方案更靠谱。
