# 对标开源方案与本地落地

## 对标对象

### 1. OpenCV ArUco

链接：[OpenCV ArUco detection](https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html)

用途：用已知尺寸的平面标记恢复像素到毫米的比例。适合包装台、仓库台面、质检台等需要可复核结果的场景。

本项目已落地：

- 生成 A4 校准卡：`GET /api/calibration-card.svg`
- 自动识别 ArUco 标记
- 优先使用标记比例测量顶部长宽和侧面高度候选

### 2. OpenCV QRCodeDetector / BarcodeDetector

链接：[OpenCV QRCodeDetector](https://docs.opencv.org/4.x/de/dc3/classcv_1_1QRCodeDetector.html)，[OpenCV BarcodeDetector](https://docs.opencv.org/4.x/d6/d25/tutorial_barcode_detect_and_decode.html)

用途：识别二维码、条码，把测量结果绑定到订单号、运单号、SKU 或仓库内部单号。

本项目已落地：

- `POST /api/orders/scan`：扫码枪键盘输入或手工录入
- `POST /api/orders/decode-image`：上传条码/二维码图片识别文本
- 测量结果保存 `order_id`、`barcode_text`、时间戳和标注图

### 3. Ultralytics YOLO

链接：[Ultralytics Docs](https://docs.ultralytics.com/)，[YOLO tasks](https://docs.ultralytics.com/tasks/)

用途：目标检测、分割、旋转框检测。对于纸箱、袋装件、异形件，YOLO 的价值主要不是直接给毫米尺寸，而是更稳地找到“物体边界/最小外接框/分割掩膜”。

建议集成方式：

- 当前 EXE 主包不内置 YOLO 权重，避免包体变大。
- 后续增加 `models/` 插件目录，检测到权重文件后启用。
- 输出统一转换为现有 `top_box_json` / `side_box_json`，复用当前测量接口。

### 4. Depth Anything V2

链接：[Depth Anything V2 GitHub](https://github.com/DepthAnything/Depth-Anything-V2)

用途：单目深度估计。它能给相对深度或经过额外标定后的深度线索，适合做“普通手机无深度相机”的增强方案。

注意边界：

- 单目深度模型一般不是天然毫米级测量工具。
- 如果要转成真实尺寸，仍需要已知尺度、相机参数、距离或现场标定。
- 模型权重会显著增加包体，不适合塞进当前小体积 EXE。

建议集成方式：

- 做成可选插件：用户有 GPU 或能接受较大包体时启用。
- 与手动框、YOLO 边界、ArUco/距离比例共同工作。

## 本次落地方案

### 无校准卡估算

新增字段：

- `camera_distance_mm`
- `focal_length_35mm`

逻辑：

1. 优先用 ArUco 标记比例。
2. 没有 ArUco 时，尝试读取 EXIF 的 `FocalLengthIn35mmFilm`。
3. 如果 EXIF 没有，就使用用户输入的 35mm 等效焦距。
4. 结合相机距离估算像素到毫米比例。
5. 返回 `camera_distance_exif_scale_used` 或 `camera_distance_manual_focal_scale_used`，并降低置信度。

### 侧面照片识别

侧面照片现在会独立执行：

- ArUco/距离比例计算
- 自动轮廓检测
- 手动框选修正
- 高度候选输出：`side_measurement.height_candidate_mm`

如果顶部长宽已经测得，且侧面高度候选可用，则 `dimensions.height_mm` 自动使用侧面高度。

### 历史记录和单号

本地 SQLite 保存位置：

- 开发运行：`D:\Documents\包装尺寸检测\data\packvision.sqlite3`
- EXE 运行：`%LOCALAPPDATA%\PackVision\packvision.sqlite3`

记录包含：

- `measurement_id`
- `created_at`
- `order_id`
- `barcode_text`
- `length_mm` / `width_mm` / `height_mm` / `volume_l`
- 上传图路径
- 标注图链接
- 完整 JSON 结果

### 手动调节标注范围

UI 里点击“手动修正框”，在标注图上拖拽矩形后自动重新测量。

内部通过：

- `top_box_json`
- `side_box_json`

把人工框传给后端。后续接 YOLO 或分割模型时，也可以直接输出同样格式。

### 异形件

当前版本对异形件采取务实方案：

1. 自动轮廓能识别时，取最小外接矩形。
2. 自动轮廓失败时，用户手动框选最大外廓。
3. 后续 YOLO/分割插件可输出更精细的掩膜或旋转框。

这比“假装普通手机单张照片可以毫米级三维重建”更可靠，也更适合仓库先落地试用。
