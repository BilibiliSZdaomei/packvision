# 深度帧质量门控

本轮新增的是 Astra Pro 到货前也能验证的深度帧质量门控。它不依赖真实相机，先用合成深度图把仓库现场最常见的风险跑通：反光、透明、深黑材质导致的深度孔洞，手抖或工件晃动导致的深度噪声，以及台面背景区域不平整。

## 新增接口

`POST /api/depth/quality`

请求字段：

- `depth_frame`：二维深度数组，单位默认是毫米。
- `roi`：目标区域 `[x1, y1, x2, y2]`，可不传；不传时检查整帧。
- `background_roi`：台面背景区域，用来判断背景深度是否稳定。
- `min_valid_depth_mm` / `max_valid_depth_mm`：有效深度范围。
- `depth_scale`：深度缩放，真实相机 SDK 如果输出不是毫米时使用。
- `noise_check`：是否检查 ROI 深度噪声；异形件目标分割流程会关闭这个检查，避免把“目标和台面本来有高度差”误判成噪声。

返回字段：

- `status`：`ok` 或 `review`。
- `roi`：目标区域有效点比例、缺失比例、中位深度、标准差、四分位差。
- `background`：背景区域同类统计。
- `quality_flags`：质量风险代码。
- `recommendation_codes`：现场处理建议代码。

## 已识别风险

- `sparse_depth_frame`：ROI 内有效深度点太少。
- `depth_hole_risk`：ROI 内缺失深度过多，常见于透明膜、亮面胶带、黑色吸光件。
- `noisy_depth_roi`：同一 ROI 的深度波动过大，常见于相机抖动、强反光、工件晃动。
- `unstable_table_depth`：背景台面不平、被杂物遮挡，或背景框选错。
- `no_valid_depth_roi`：ROI 内没有任何有效深度。

## 已接入的测量流程

- `measure_depth_roi`：标准纸箱、规则包装的深度 ROI 测量会自动合并质量门控结果。
- `measure_depth_object_mask`：保险杠饰条、管件、软包、异形件的点云外接尺寸测量会自动合并孔洞和背景稳定性风险。
- 前端三语标签已补齐，结果区会显示质量标记和处理建议。

## 现场处理建议

- 反光或透明包装：换角度采集，必要时在非关键表面贴一小段哑光胶带帮助深度相机取点。
- 黑色吸光件：补柔和侧光，避免直射强光和大面积阴影。
- 长条件：优先固定相机和工件，目标框覆盖完整长度，必要时分段采集后人工复核。
- 异形件：使用目标掩膜流程，不要只用一个大矩形框当最终尺寸。
- 台面背景：背景框要选平整、干净、没有包装边缘或杂物的区域。

## 和校准卡的关系

深度相机到货后，常规测量不要求仓库人员手动输入手机内参，也不要求每次摆校准卡。深度相机 SDK 会提供深度图和相机内参，本项目的目标是把这些参数封装在采集层里。校准卡仍然可以作为抽检工具，用于新工位首次上线、相机移动后复核、月度精度巡检。
