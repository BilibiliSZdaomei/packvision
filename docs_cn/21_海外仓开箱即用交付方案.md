# PackVision 海外仓开箱即用交付方案

> 日期：2026-05-28  
> 目标：让其他国家仓库提前把相机、线材、标定板、驱动和现场样品准备好。你到现场后，只需要把交付包复制过去，接上相机，跑体检，直接开始验证。

## 1. 先说清楚：哪些能开箱即用，哪些必须提前装

PackVision 可以做到 **软件交付包开箱即用**，但深度相机不能完全免驱动。

| 场景 | 是否可以只靠 PackVision.exe | 说明 |
| --- | --- | --- |
| 手机照片/上传图片测量 | 可以 | 只需要 `PackVision.exe`，不需要相机驱动。 |
| 扫码、单号、历史记录、CSV 导出 | 可以 | 数据保存在本机用户目录，适合普通仓库电脑。 |
| Astra Pro 深度相机实时采集 | 不能完全免驱动 | 目标电脑必须先安装 Astra Pro Windows 驱动，并用 OrbbecViewer 确认深度画面。 |
| 三视图/多相机 | 需要现场调试 | 需要 USB 供电、端口稳定性、相机固定位置和序列号绑定。 |

结论：**交付包可以开箱即用；深度相机必须提前完成驱动和上位机验证。**

## 2. 现在项目新增的开箱即用能力

### 新增接口

```text
GET /api/deployment/readiness
GET /api/review/samples
GET /api/review/export.csv
```

它会检查：

- 当前 PackVision 版本。
- 是否能跑图片版测量。
- 本地历史和结果目录是否可写。
- `dist\PackVision.exe` 是否存在、大小是否适合传输。
- Astra Pro 厂商资料、驱动安装包、OrbbecViewer、OpenNI runtime 是否存在。
- 是否已经检测到深度相机。
- 目标仓库到货前必须准备哪些东西。
- 到现场后的操作顺序。

复核接口会把低置信、失败、异常材质、人工修正和多视角冲突记录集中起来，方便现场导出 CSV、补充人工真值、形成后续误差报告。

### 新增脚本

```powershell
PowerShell -ExecutionPolicy Bypass -File .\scripts\check_astra_depth_status.ps1
```

用途：在开发机或现场电脑上做体检。

- 在项目源码目录运行：直接调用 Python 服务输出完整 JSON。
- 在现场交付包目录运行：如果只有 `PackVision.exe`，脚本会启动 EXE，并访问本地 API 读取体检结果。

### 新增交付包脚本

```powershell
PowerShell -ExecutionPolicy Bypass -File .\scripts\build_handoff_package.ps1
```

用途：生成可以复制到海外仓电脑的现场包。

默认输出到：

```text
D:\Documents\包装尺寸检测\release
```

压缩包默认限制：

```text
100 MB
```

如果超过 100 MB，脚本会直接报错，避免后面传输失败。

## 3. 给海外仓提前准备的清单

这份清单可以直接发给国外仓库。

### 必须准备

| 项目 | 要求 | 怎么确认 |
| --- | --- | --- |
| Astra Pro 相机 | 至少 1 台，建议贴上编号 | 相机外壳贴 `TOP-01` 之类的标签。 |
| Windows 电脑 | Windows 10/11，64 位，普通办公电脑即可 | 能插 USB，能运行 EXE。 |
| Astra Pro 驱动 | 提前安装厂商 Windows Sensor Driver | 设备管理器能看到 Orbbec/Astra 设备。 |
| OrbbecViewer | 提前放到电脑上 | 能打开彩色、深度、红外、点云画面。 |
| USB 数据线 | 优先用相机原装线；如果相机是固定 USB-A 线，长度不够就准备主动 USB-A 公对母延长线 | 插上后 Windows 能识别设备。 |
| 标定板 | 打印 PackVision A4 ArUco 标定卡，100% 原比例，不要缩放 | 用尺子量打印尺寸，不能“适应页面”。 |
| 固定支架 | 三脚架、俯拍支架或固定臂 | 相机角度不能每次测量都变。 |
| 工作台 | 哑光、稳定、不反光 | 避免透明桌垫、亮面金属、强反光背景。 |
| 真值工具 | 卷尺、卡尺、已知尺寸纸箱 | 用来填现场验收 CSV。 |

### 建议准备

| 项目 | 什么时候需要 |
| --- | --- |
| 有源 USB 3.x Hub | 电脑 USB 口不够、两台或三台相机、供电不稳定时。 |
| USB-A 主动延长线 | 相机需要离电脑更远，但不要用普通超长无源线。 |
| 补光灯 | 仓库光线不稳定、阴影严重、黑色/反光件较多时。 |
| 黑色/反光/透明样品 | 提前做异常材质验证。 |
| 厂商棋盘格标定板 | 只给工程复核用，日常仓库员工不需要操作。 |

## 4. 数据线到底准备什么

当前项目按 Astra Pro 厂商资料中的 `USB2.0` 接口来适配。实际购买的 Astra Pro 批次可能有两种情况：

1. **相机自带固定 USB-A 线**：这种最常见。电脑端是普通 USB-A 插头。需要延长时，买 **USB-A 公对 USB-A 母主动延长线**，不要买只能充电的线。
2. **相机是可拆线版本**：优先用商家原装线。如果要另买，按相机端口买对应的数据线，并确保是数据线，不是充电线。不要凭感觉买 Type-C，除非相机端确实是 Type-C。

现场第一轮验证不要先接 Hub，顺序是：

```text
电脑 USB 口直连 -> OrbbecViewer 有画面 -> PackVision 体检通过 -> 再考虑 Hub/延长线/多相机
```

两台或三台相机时，建议：

- 用有源 USB Hub。
- 每台相机贴序列号/角色标签：`top`、`front`、`side`。
- 先单台验证，再逐台增加。
- 多相机不稳定时，优先排查供电和 USB 带宽，不要先怀疑算法。

## 5. 标定板怎么准备

### PackVision A4 ArUco 标定卡

打开 PackVision 后访问：

```text
http://127.0.0.1:8765/api/calibration-card.svg
```

打印要求：

- A4 纸。
- 100% 原比例。
- 不要“适应页面”。
- 打印后用尺子量 marker 尺寸。
- 纸张保持平整，最好贴在硬纸板上。

用途：

- 手机照片/图片上传测量时，提供可靠比例尺。
- 深度相机异常时，做工程复核。
- 给现场人员一个简单可理解的检查物。

### 厂商棋盘格标定板

厂商资料中有棋盘格标定板和 ROS 标定教程。它不是仓库员工日常要用的东西。

使用原则：

- 默认优先使用 Astra Pro 厂商/ROS/OpenNI 输出的 `camera_info`。
- 只有发现深度相机误差异常、内参不可信、或者换相机后精度不稳定时，工程人员再走棋盘格标定。
- 仓库员工不需要输入焦距、光圈、内参矩阵。

## 6. 到现场后的 30 分钟顺序

1. 把交付包复制到目标电脑本地目录，不要直接在 U 盘里运行。
2. 插一台 Astra Pro，不接 Hub。
3. 打开 OrbbecViewer。
4. 确认彩色、深度、红外、点云都有画面。
5. 运行：

```powershell
PowerShell -ExecutionPolicy Bypass -File .\check_astra_depth_status.ps1
```

6. 如果有 `blocker`，先处理 blocker。
7. 双击 `PackVision.exe`。
8. 打开：

```text
http://127.0.0.1:8765
```

9. 先用标准纸箱测量。
10. 再测长条件、异形件、反光/黑色/透明材质。
11. 所有测试都输入单号或样品编号。
12. 导出历史记录和试运行 CSV。

## 7. 现场验收样品

最低样品建议：

| 类型 | 数量 | 目的 |
| --- | ---: | --- |
| 标准纸箱 | 5 | 验证基础长宽高精度。 |
| 长条件 | 5 | 验证主轴测量和超长件。 |
| 异形件/软包 | 5 | 验证 mask 和人工复核流程。 |
| 黑色/反光/透明材质 | 5 | 验证深度孔洞和异常材质提示。 |
| 已知尺寸标准物 | 2 | 作为现场基准样。 |

验收标准先按当前项目目标：

- 标准纸箱：单边中位误差目标 `10 mm` 或 `2%` 内。
- 长条件：不能短报；宁可提示复核，也不能高置信给错。
- 异形件：允许进入人工复核，但必须保存原图、标注图、单号和历史。
- 异常材质：必须有风险提示，不能静默通过。

## 8. 如果现场出问题，先按这个查

| 现象 | 优先排查 |
| --- | --- |
| Windows 不识别相机 | 数据线是不是只能充电、驱动是否安装、USB 口是否供电不足。 |
| OrbbecViewer 没深度图 | 驱动、OpenNI runtime、相机距离是否小于 0.6m、是否被其他程序占用。 |
| PackVision 探测不到相机 | 先确认 OrbbecViewer 有画面，再运行 readiness 脚本，看 OpenNI 和 capture backend。 |
| 多相机不稳定 | 先单台验证，再换有源 Hub，最后绑定序列号。 |
| 反光/黑色件误差大 | 调角度、换哑光背景、补光、进入人工复核。 |
| 图片版测不准 | 打印 ArUco 标定卡，确认没有缩放，或者改用深度相机。 |

## 10. 我的后续开发判断

这一轮之后，PackVision 的“开箱即用”目标拆成三层：

1. **图片版开箱即用**：EXE + 本地 UI + 历史记录 + 导出，已经可以直接跑。
2. **深度相机版准开箱即用**：需要目标电脑提前装好驱动和 OrbbecViewer，PackVision 提供体检、探测、测量和文档。
3. **多相机工业版**：需要支架、供电、相机编号、外参/视角验证，不能假装零调试。

真正落地时，不要承诺“相机插上 100% 免配置”。正确说法是：

> PackVision 交付包可以复制即用；Astra Pro 相机需要目标电脑先完成驱动和官方上位机验证。现场用 readiness 脚本确认环境，再进入测量。
