# 手机照片内参与光照质量门控

本文档回答两个现场问题：

1. 仓库员工只会扫码、拍照、放件，不能要求他们填写相机内参、焦距、距离。
2. 手机照片和深度相机都会受到光照、反光、透明、深黑材质影响，系统必须自动提示复拍或人工复核。

## 1. 为什么不能直接稳定读取照片内参

普通 JPEG/微信图片/相册图片通常只能拿到部分 EXIF，例如手机型号、焦距、光圈、ISO、快门和图片尺寸。真实测量需要的是：

```text
fx / fy 像素焦距
cx / cy 主点
镜头畸变参数
当前使用的具体镜头
是否数码变焦或裁切
相机到物体的真实距离
物体姿态和深度
```

这些字段在普通上传照片里经常不存在，或者被压缩软件删除。Android Camera2 和 iPhone ARKit 可以在原生采集流程里拿到更多相机参数，但这不是“仓库员工随手从相册上传一张照片”能够稳定依赖的能力。

因此 PackVision 的原则是：

```text
仓库默认模式：不要求员工填写内参
手机照片：自动读取能拿到的 EXIF，拿不到就降级为估算/复核
距离和焦距输入：只放在高级估算参数里
深度相机：作为正式仓库测量主路径
```

## 2. 有深度相机后还要不要校准卡

日常仓库测量不要求每件都放校准卡。

Astra Pro 深度相机接入后，正式路径应当使用深度帧、相机内参和 ROI/mask 计算真实尺寸。员工只需要：

```text
扫码
放件
拍摄/测量
必要时按提示复拍
```

校准卡仍然保留为备用工具：

- 手机无深度、无可靠 EXIF 时，用校准卡能提升二维尺度可信度。
- 到货验收阶段，用已知尺寸纸箱/长条件/异形件和 CSV 模板做真值对比。
- 每天或每周可以用固定标准箱抽测，确认工位没有明显漂移。

## 3. 光照质量门控

当前代码新增：

```text
POST /api/capture/quality
```

它会检测上传图片：

- `lighting_overexposed`：过曝，常见于阳光直射、强反光桌面。
- `lighting_underexposed`：欠曝，常见于暗光仓库角落。
- `low_contrast_capture`：对比度过低，边缘不清晰。
- `blurry_capture`：照片模糊或手抖。

对应建议：

- `retake_away_from_direct_light`：避开直射光或强反光后重拍。
- `add_stable_indoor_light`：补充稳定室内光源。
- `retake_on_plain_background`：换纯色/哑光背景。
- `stabilize_camera_or_tripod`：固定手机或相机后重拍。

这些质量标记也会合并进 `POST /api/measure` 的 `quality_flags` 和 `recommendation_codes`。

## 4. 对汽车备件场景的处理原则

```text
普通纸箱：
  优先自动测量，光照异常时提示复拍。

长条件：
  优先深度 ROI，要求完整入画；手机照片只能给低置信估算。

异形件/软包：
  优先深度 object mask，保留人工框选和复核。

反光/透明/深黑件：
  默认进入材质风险和人工复核流程，不让算法假装高精度。
```

## 5. 给现场人员的简化话术

现场 SOP 不要写“输入焦距/内参”。应该写成：

```text
1. 扫单号。
2. 把包装放到哑光台面。
3. 避开阳光直射和强反光。
4. 点测量。
5. 如果系统提示过曝、太暗、模糊，就按提示重拍。
6. 如果是透明、反光、深黑或软包，按系统提示人工复核。
```
