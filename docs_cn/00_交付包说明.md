# PackVision 交付包说明

本次交付分为两个压缩包，均遵守“每个压缩包不超过 100 MB”的限制。

## 1. PackVision Local 项目包

内容包括：

- `dist/PackVision.exe`：Windows 本地可执行文件。
- `packvision/`：FastAPI 后端、OpenCV 测量算法、静态前端 UI。
- `docs/`：初版方案和落地路线。
- `docs_cn/`：详细中文介绍文档。
- `scripts/build_exe.ps1`：重新打包 EXE 的 PowerShell 脚本。
- `tests/`：接口和测量算法的基础测试。

使用方式：

1. 双击或运行 `dist/PackVision.exe`。
2. 浏览器打开 `http://127.0.0.1:8765`。
3. 打印 `/api/calibration-card.svg` 校准卡。
4. 上传顶部照片，可选上传侧面照片或手动输入高度。

## 2. GitHub 对标项目包

内容包括 4 个对标仓库源码快照：

- `Practical-CV/Measuring-Size-of-Objects-with-OpenCV`
- `Ali619/Object-Detection-Size-Measurement`
- `david-s-martinez/Automatic-Workspace-Calibration-Based-on-Aruco`
- `cmower/aruco_markers`

同时包含中文说明：

- 每个项目的功能定位。
- 核心算法流程。
- 运行依赖和入口。
- 对 PackVision 的借鉴价值。
- 局限和二次开发建议。

## 重要说明

GitHub 直连 `git clone` 在本机网络下不稳定，所以本次采用 GitHub 官方 zipball 下载源码快照。包内不包含完整 `.git` 历史，但源码、示例图片、README、LICENSE 等项目文件均已保留，适合阅读、学习和二次整合。
