# PackVision 仓库日常操作流程

[[00 PackVision 知识地图|返回知识地图]]

> [!tip] 给仓库员工的话
> 你不用懂相机。正常流程就是：扫码，放好，测量，看结果，必要时重拍或叫人复核。

## 标准流程

1. 扫描单号条码。
2. 把包装或备件放到测量台。
3. 点击测量，默认走 Astra Pro 深度相机；没有接相机或主动上传照片时，才走图片兜底。
4. 看结果：长、宽、高、体积、计费重量。
5. 如果系统提示异常，按提示重拍、换角度或人工复核。
6. 保存记录，结果进入历史。

## 三种录入单号方式

- 扫描枪扫条码。
- 上传条码图片识别。
- 手动输入单号。

## 什么情况算异常

- 深度相机没连接。
- 包装太反光。
- 黑色橡胶件吸光，深度图缺失。
- 透明塑料袋或灯罩测不准。
- 长条件超出台面或画面。
- 异形件轮廓被遮挡。

遇到这些情况先看：[[08 现场排错手册]]

## 仓库不需要选模式

系统应该自动判断：

- 标准纸箱：按规则包装测。
- 长条件：优先看最长方向。
- 异形件：用深度 object-mask。
- 大件异形：多角度或人工复核。

## 结果保存在哪里

项目会保存：

- 测量时间。
- 单号。
- 条码内容。
- 测量尺寸。
- 体积和计费重量。
- 质量标记。
- 是否保存历史。
- 调用次数和测量次数。

主管看统计时读：[[05 PackVision 接口与数据流#后台统计]]

历史、统计和复核都在 UI 的“数据中心”。仓库员工日常只盯工作台；主管或工程人员再去数据中心导出记录、复核低置信样本、看使用次数。
