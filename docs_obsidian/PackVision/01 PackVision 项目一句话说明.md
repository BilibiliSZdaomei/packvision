# PackVision 项目一句话说明

[[00 PackVision 知识地图|返回知识地图]]

## 这个项目到底干嘛

PackVision 是给仓库测包装尺寸用的软件。

它要解决的问题很简单：

> 包装、异形件、长条汽车备件，人工量尺寸慢、不稳定、不好追溯。我们希望用手机图片和深度相机，把长宽高、体积、计费重量、单号、历史记录都自动留好。

## 谁用

- 仓库员工：扫码、放件、点测量。
- 主管：看测量次数、异常、历史记录。
- 工程师：装驱动、调相机、看接口、做误差验证。

## 仓库员工不应该做什么

- 不手动填焦距、光圈、相机内参。
- 不选择复杂算法模式。
- 不理解 OpenNI、点云、标定矩阵。
- 不靠记忆保存结果。

## 系统应该自动做什么

- 自动识别或读取单号。
- 自动选择测量流程。
- 自动保存历史记录。
- 自动记录调用次数和测量次数。
- 自动给出质量提示，比如反光、透明、黑色吸光、深度空洞。
- 自动支持普通包装、长条件、异形件。

## 两条技术路线

1. 手机/普通图片路线：没有摄像头时先跑起来，适合上传图片和人工校正。
2. 深度相机路线：Astra Pro 到货后成为主路线，用深度图和点云测量真实 3D 尺寸。
