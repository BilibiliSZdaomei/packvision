# 现场试运行验收报告

[[00 PackVision 知识地图|返回知识地图]]

> [!summary] 结论
> PackVision 现在可以导出现场试运行报告，把 readiness、实时工位、历史、复核、使用统计、电子秤和 WMS/TMS 队列合成一份可汇报证据。

## 接口

```text
GET /api/deployment/field-trial-report
GET /api/deployment/field-trial-report.md
```

## 四种结论

| 状态 | 含义 |
| --- | --- |
| `needs_attention` | 环境还有阻断项。 |
| `pre_hardware_ready` | 相机到货前准备就绪，但真实深度相机还没验证。 |
| `sample_collection_needed` | 需要保存现场真值样本。 |
| `field_trial_ready` | 可进入现场试运行。 |

## 为什么重要

- 防止把模拟实时流误说成真实硬件验收。
- 到每个国家仓库后，都能立刻导出一份状态报告。
- 老板看报告能知道“能不能试运行、还差什么、下一步怎么做”。
- 工程师看报告能定位是驱动、相机、电子秤、历史、复核还是 WMS/TMS 问题。

## UI 入口

数据中心 → 验收报告 → 刷新报告 / 导出 Markdown。
