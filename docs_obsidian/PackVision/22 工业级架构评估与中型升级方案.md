# 工业级架构评估与中型升级方案

## 结论

不推倒重来，做中型升级。

当前 PackVision 的本地优先模块化单体适合海外仓开箱即用。真正缺的是工位编排层，让尺寸、称重、扫码、证据、接口同步统一成一个主状态。

使用逻辑也要修正：主流程不是上传照片，而是连接 Astra Pro 后实时监控、自动测量、稳定后记录。照片上传只保留为无硬件、离线复核和异常纠错的兜底。

## 新增核心

`packvision/services/station.py`

`GET /api/station/snapshot`

它负责输出：

- 工位状态。
- DWS 能力状态。
- 当前实时候选。
- 最新历史记录。
- 工业级缺口。
- 下一阶段升级轨道。

## DWS 标准

- Dimensioning：尺寸采集。
- Weighing：称重和体积重。
- Scanning：单号/条码。
- Evidence：图片、深度、点云证据。
- Integration：WMS/TMS/API/CSV。

## UI 调整

- 工作台首屏显示顶部、正面、侧面三路相机监控矩阵。
- 单台 Astra Pro 阶段只点亮当前相机视角，其余视角显示待接入。
- 后续两台/三台相机接入时，不需要重做 UI，只把对应角色绑定到相机配置。
- 主按钮是“记录当前稳定结果”，不是“按一下才开始测量”。
- “照片兜底测量”放在辅助入口，避免仓库员工误解主流程。
- 顶部状态条接入 `/api/station/snapshot` 和 `/api/deployment/readiness`，直接显示工位编排成熟度和到货验收状态。
- 电子秤能力接入 `/api/scale/status`，基础包保持手动实重兜底，后续接 USB HID/RS232 adapter。

## 不大型重构的原因

- Astra Pro 还没真实插机验证。
- 海外仓普通电脑更适合轻量本地部署。
- 当前 service 层已经能继续拆分。
- 先补编排层，比重写前后端更稳。
