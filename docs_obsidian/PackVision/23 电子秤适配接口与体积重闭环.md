# 电子秤适配接口与体积重闭环

## 一句话

尺寸只是 DWS 的一半，PackVision 需要同时处理实重、体积重和计费重。当前先做轻量 adapter 接口，没接电子秤时手动输入，接秤后自动读数。

## 接口

```text
GET /api/scale/status
POST /api/scale/read
```

## 状态

- `manual_ready`：默认手动实重兜底。
- `auto_weight_ready`：电子秤已有稳定读数。
- `auto_weight_unstable`：秤端返回未稳定读数。
- `adapter_configured_waiting`：adapter 已配置，等待稳定重量。
- `adapter_error`：串口、协议或端口异常，继续保留手动输入。

## 配置

- 默认：`manual_entry`
- 演示：`PACKVISION_SCALE_SOURCE=mock`，`PACKVISION_MOCK_SCALE_KG=7.35`
- RS232：`PACKVISION_SCALE_SOURCE=rs232_serial`，`PACKVISION_SCALE_SERIAL_PORT=COM7`
- 可选：`PACKVISION_SCALE_SERIAL_BAUDRATE=9600`
- 后续：`usb_hid`

常见串口格式已支持：

```text
ST,GS,+   7.350kg
US,GS,+001250 g
ST,+ 10.0 lb
```

## UI

工作台重量区域显示电子秤状态，并有“读取电子秤”按钮。读到电子秤重量后，自动填入实重并重新计算计费重。

## 取舍

基础包只放轻量 `pyserial`，不放重型厂商驱动。不同国家仓库换电子秤时，只新增 adapter，测量、计费、历史和统计流程不推翻。
