# 设备守护与现场恢复

> [!summary] 结论
> 设备 watchdog 是 PackVision 从 demo 走向现场试运行的关键层：它把驱动、OpenNI、相机枚举、实时流卡顿、模拟兜底，转成仓库人员能执行的恢复动作。

## 核心接口

```text
GET /api/device/watchdog
```

它会返回：

- `status`：设备状态。
- `severity`：`ok`、`warning`、`critical`。
- `safe_to_record_live`：是否可作为正式发货尺寸记录。
- `dry_run_record_available`：是否可用于演示/干跑。
- `signals`：设备数、实时流、FPS、更新时间。
- `issues`：问题列表。
- `recovery_steps`：恢复步骤。

## 状态解释

| 状态 | 说明 |
| --- | --- |
| `live_camera_active` | 真实相机实时流正常。 |
| `camera_detected_idle` | 相机已识别，但实时流未启动。 |
| `simulation_fallback` | 正在使用模拟兜底，不能作为正式发货尺寸。 |
| `no_camera_detected` | OpenNI 可用，但没检测到相机。 |
| `live_stale` | 实时流卡住或长时间未更新。 |
| `runtime_not_ready` | OpenNI/采集后端不可用。 |
