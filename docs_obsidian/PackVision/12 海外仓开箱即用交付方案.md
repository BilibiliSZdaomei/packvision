# 海外仓开箱即用交付方案

> [!summary] 核心判断
> PackVision 软件包可以做到复制即用；Astra Pro 深度相机不能完全免驱动，目标电脑必须提前安装驱动并用 OrbbecViewer 验证画面。

## 交付分层

| 层级 | 能力 | 准备要求 |
| --- | --- | --- |
| 图片版 | 上传手机照片、扫码、单号、历史、CSV 导出 | 只需要 `PackVision.exe` |
| Astra Pro 版 | 深度相机采集、真实三维测量、质量门控 | 需要驱动、OrbbecViewer、数据线、支架 |
| 多相机版 | top/front/side 三视图融合 | 需要有源 Hub、相机编号、固定支架、现场验证 |

## 新增体检接口

```text
GET /api/deployment/readiness
```

它会告诉我们：

- 图片版能不能跑。
- EXE 是否存在，大小是否适合传输。
- 历史和结果目录是否可写。
- Astra Pro 厂商资料、驱动、OrbbecViewer、OpenNI runtime 是否存在。
- 目标仓库还缺哪些物理准备。
- 到现场后应该按什么顺序操作。

## 新增脚本

开发机体检：

```powershell
PowerShell -ExecutionPolicy Bypass -File "D:\Documents\包装尺寸检测\scripts\check_astra_depth_status.ps1"
```

生成交付包：

```powershell
PowerShell -ExecutionPolicy Bypass -File "D:\Documents\包装尺寸检测\scripts\build_handoff_package.ps1"
```

交付包目录现场体检：

```powershell
PowerShell -ExecutionPolicy Bypass -File .\check_astra_depth_status.ps1
```

## 给海外仓提前准备

- 安装 Astra Pro Windows 驱动。
- 桌面保留 OrbbecViewer。
- 准备 Astra Pro 原装 USB 线；如果是固定 USB-A 线且不够长，准备 USB-A 公对母主动延长线。
- 准备有源 USB 3.x Hub，供两台或三台相机验证时使用。
- 打印 PackVision A4 ArUco 标定卡，100% 原比例。
- 准备相机支架，保证相机角度不动。
- 准备哑光工作台和稳定光照。
- 准备卷尺/卡尺、标准纸箱、长条件、异形件、黑色/反光/透明样品。

## 到现场 30 分钟顺序

1. 把交付包复制到目标电脑本地目录。
2. 插一台 Astra Pro，先不要接 Hub。
3. 打开 OrbbecViewer，确认彩色、深度、红外、点云。
4. 运行 `check_astra_depth_status.ps1`。
5. 处理 blocker。
6. 双击 `PackVision.exe`。
7. 打开 `http://127.0.0.1:8765`。
8. 先测标准纸箱，再测长条件、异形件、异常材质。
9. 每个样品都录入单号或样品编号。
10. 导出历史 CSV 和试运行 CSV。

## 标定板原则

- 日常仓库员工不输入焦距、光圈、内参。
- 深度相机优先用厂商/ROS/OpenNI 输出的 `camera_info`。
- PackVision ArUco 标定卡用于图片版和现场复核。
- 厂商棋盘格只给工程师排查精度异常时使用。
