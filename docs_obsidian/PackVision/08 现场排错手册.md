# PackVision 现场排错手册

[[00 PackVision 知识地图|返回知识地图]]

## 相机没画面

先做：

1. 换 USB 口。
2. 换数据线，不要用只能充电的线。
3. 打开 `D:\app\orbbec-astra-pro\启动上位机.bat`。
4. 看 OrbbecViewer 是否有 Color 和 Depth。
5. 运行 `D:\app\orbbec-astra-pro\检查Astra安装.ps1`。

如果上位机都没画面，先别调 PackVision。

## PackVision 显示 no device

可能原因：

- 相机没插好。
- 驱动没装好。
- OpenNI runtime 没加载。
- 多台相机时 USB 供电不稳。

目标状态：

- 没插相机：`openni_runtime_ready_no_device`
- 插上相机：`ready_for_capture`

## 材质问题

### 黑色件

问题：吸红外，深度点少。

处理：

- 换角度。
- 增加人工复核。
- 不要让系统强行自动通过。

### 反光件

问题：镜面反射导致深度飘。

处理：

- 避免强光直射。
- 换角度。
- 记录材质风险。

### 透明件

问题：红外穿透，深度不可靠。

处理：

- 使用包装外轮廓。
- 必要时人工复核。

## 尺寸明显不准

先检查：

- 相机距离是否小于 0.6m。
- 相机是否晃动。
- 台面是否反光。
- ROI 是否框错。
- 背景 ROI 是否选到物体上。

再检查：

- 是否需要导入 ROS camera_info。
- 是否需要工程师用棋盘格重新标定。

相关基础：[[03 Astra Pro 深度相机新手教程#校准卡是不是必须]]

## 多相机不稳定

先不要买主板。

按顺序试：

1. 电脑本体不同 USB 口。
2. 短数据线。
3. 有源 USB Hub。
4. 给每台相机配置 `serial_hint`。
5. 仍然掉帧时，再考虑 PCIe USB 扩展卡或更强主机。

规划见：[[06 多相机三视图方案]]
