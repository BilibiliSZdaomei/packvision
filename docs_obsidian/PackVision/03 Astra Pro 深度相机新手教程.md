# Astra Pro 深度相机新手教程

[[00 PackVision 知识地图|返回知识地图]]

## 深度相机是什么

普通照片只知道“这个点是什么颜色”。

深度相机还知道“这个点离相机有多远”。

所以它能生成一张深度图：

- 白/亮：可能离相机近。
- 黑/暗：可能离相机远。
- 数值：通常可以理解成毫米级距离。

PackVision 用这些距离算长、宽、高。

## Astra Pro 的关键参数

| 项目 | 简单理解 |
| --- | --- |
| 工作原理 | 红外结构光深度相机 |
| 深度范围 | 大约 0.6m 到 8m |
| 常用深度分辨率 | 640x480@30FPS |
| 标称精度 | 1m 距离约 +/-3mm |
| 接口 | 相机规格是 USB2.0，但现场建议插稳定 USB3.x 口或有源 Hub |
| 功耗 | 约 2.5W，峰值 500mA |

## 它为什么比手机照片可靠

手机照片要靠比例、焦距、EXIF、参考物推断尺寸。

深度相机直接给每个点的距离，所以更适合：

- 纸箱。
- 长条件。
- 保险杠、饰条、软包等异形件。
- 需要追溯和重复测量的仓库场景。

## 它也不是万能的

深度相机怕这些东西：

- 黑色橡胶：吸收红外。
- 镜面金属：反光。
- 透明塑料：红外穿透或丢深度。
- 强阳光：干扰红外结构光。
- 太近：0.6m 以下不适合作为主测量距离。

这些情况看：[[08 现场排错手册#材质问题]]

## 校准卡是不是必须

仓库日常不需要校准卡。

正确顺序是：

1. 优先用厂商驱动、OpenNI、ROS camera_info 或设备参数。
2. 工程师发现误差异常时，再用厂商资料包里的棋盘格标定板复核。
3. 仓库员工不要手动输入相机参数。

PackVision 里对应的厂商标定板入口是：

```text
http://127.0.0.1:8765/api/depth/vendor-calibration-board.pdf
```

旧的 ArUco 卡只保留给手机照片兜底，不作为 Astra Pro 主标定入口。
