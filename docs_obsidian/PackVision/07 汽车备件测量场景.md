# 汽车备件测量场景

[[00 PackVision 知识地图|返回知识地图]]

## 1. 标准纸箱

典型备件：

- 滤芯。
- 火花塞。
- 小传感器。
- 刹车片。
- 维修套件。

建议：

- 用顶视图或深度 ROI。
- 包装尽量摆正。
- 背景 ROI 放在空桌面。

## 2. 长条件

典型备件：

- 减震器。
- 雨刮。
- 拉杆。
- 饰条。
- 排气管局部件。

建议：

- 让最长方向完整进入画面。
- 用主轴测量，不只看矩形框。
- 超长时进入人工复核或多相机方案。

## 3. 异形件 / 软包

典型备件：

- 保险杠饰条。
- 轮眉。
- 格栅。
- 管件。
- 泡棉保护件。

建议：

- 用 `object_mask`。
- 不要把 ROI 内空白区域都算成物体。
- 背景台面要稳定、少反光。

## 4. 反光、透明、黑色件

典型问题：

- 金属反光导致深度错。
- 透明塑料袋丢深度。
- 黑色橡胶吸红外。

建议：

- 系统提示异常时不要硬过。
- 换角度、换光照、加人工复核。
- 必要时记录 `material_hint`。

## 5. 大件异形

典型备件：

- 保险杠。
- 大灯总成包装。
- 大型外饰件。

建议：

- 一台相机先做试运行。
- 如果遮挡明显，再加前视/侧视。
- 最终走 [[06 多相机三视图方案]]。
