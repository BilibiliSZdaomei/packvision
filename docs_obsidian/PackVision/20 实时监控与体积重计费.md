# 实时监控与体积重计费

## 一句话

相机一直测，仓库人员只负责扫码、称重、确认保存；系统自动算体积重和计费重。

## 现场界面应该看什么

- **实时状态**：等待放件、检测中、稳定可记录、需复核。
- **采集监控**：FPS、运行时长、测量次数、采集后端。
- **尺寸候选**：长、宽、高持续刷新。
- **重量监控**：实重、体积重、计费重、计费来源。

## 计费重公式

```text
体积重 = 体积 L / 规则系数
计费重 = max(实重, 体积重)
```

默认规则：

| 规则 | 含义 |
| --- | --- |
| `express_5000` | 快递/空运，体积 L / 5 |
| `standard_6000` | 默认仓配，体积 L / 6 |
| `economy_8000` | 经济陆运，体积 L / 8 |

## 和 PackVision 的关系

- UI：工作台常驻实重输入和体积重规则选择。
- API：`/api/weight/volumetric-rules` 提供规则表。
- 历史：保存实重、体积重、规则、计费来源和计费重。
- 实时流：`/api/depth/live/state` 返回 FPS、运行时长和测量次数。
