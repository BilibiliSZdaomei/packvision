# 包装尺寸检测方案对标与落地路线

## 结论

不使用深度相机也能做可用 MVP，但需要明确拍照约束：参考标记必须与待测平面共面，顶视图测长宽，侧视图或人工输入补高度。商业级自动量方通常会使用深度/多相机、称重、条码/OCR 和照片证据链。

## 对标方向

- 物流量方硬件：静态尺寸仪、DWS 设备、带照片证据的包裹量方系统。
- 手机/单目路线：参考物、ArUco/棋盘格、透视校正、多视图补高度。
- 进阶路线：ARCore/ARKit 深度、双目/结构光、ToF 深度相机、COLMAP 多视图重建。

## 项目落地

1. 首版先做上传接口、标注图、测量结果、置信度和质量提示。
2. UI 做成本地工作台，而不是宣传页：上传、测量、校准卡、结果证据在同一个界面。
3. 算法以 OpenCV ArUco 作为参考尺度，先测长宽，高度通过侧面图或人工输入补齐。
4. 数据结构保留 `method`、`quality_flags`、`artifacts`，便于后续引入相机、电子秤、扫码、订单号。
5. 打包采用 PyInstaller 单文件 EXE，减少部署门槛。

## 后续增强

- 加入相机实时采集：USB 摄像头或工业相机。
- 引入透视校正：让用户点选四角或自动检测包裹顶面。
- 增加双图/三图工作流：顶部、正面、侧面合成三维尺寸。
- 加入条码/OCR 和重量字段：形成仓库可追溯记录。
- 深度硬件版本：RealSense、Orbbec、Azure Kinect 等。
